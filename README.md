
# Retail Sales Prediction & Inventory Monitoring

## Project Overview
An AI-based retail analytics system that predicts sales and monitors inventory risk using historical retail data.

## Features
- Sales prediction
- Historical sales analysis
- Promotion analysis
- Inventory monitoring
- Stockout detection
- Reorder risk identification
- Interactive Streamlit dashboard

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit
- Matplotlib

## Datasets
- Sales Daily
- SKU Master
- Calendar
- Inventory Snapshots

## Machine Learning
Random Forest Regression is used to predict the expected number of units sold.

## Evaluation Metrics
- MAE
- RMSE
- R² Score

## Application
The Streamlit dashboard provides sales predictions and inventory monitoring.
